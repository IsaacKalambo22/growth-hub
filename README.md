# growth-hub

I am Isaac Kalambo, a software developer, director of operations and qualified teacher based in Lilongwe, Malawi. This repo is where I plan, track and show my growth over 12 months, in public, one week at a time.

## The three tracks

| Track | What it covers | Where it lives |
|---|---|---|
| A. Platform | The e-learning platform I am building | A separate private repo |
| B. Tech skills | 12 skills, each tied to a small project | [tech/](tech/) and [plans/B-tech-skills.md](plans/B-tech-skills.md) |
| C. Personal and professional growth | Leadership, communication, business, money, health, values | [growth/](growth/README.md) and [plans/C-personal-professional-growth.md](plans/C-personal-professional-growth.md) |

The quarter-by-quarter view is in [ROADMAP.md](ROADMAP.md).

## Folder map

```
growth-hub/
├── ROADMAP.md          Quarterly plan for Tracks B and C
├── plans/              Source plans (single source of truth)
├── tech/               One folder per skill: README, exercises/, links.md
├── growth/             Books, talks, SOP templates, reviews, checklists
├── logs/
│   ├── weekly/         One file per ISO week (e.g. 2026-W41.md)
│   └── monthly/        One file per month (e.g. 2026-10.md)
└── .github/            Issue templates for learning and growth goals
```

## How I use it each week

- **Monday:** copy [logs/weekly/_template.md](logs/weekly/_template.md) to this week's file, set the skill focus and top 3 priorities.
- **During the week:** build, add exercises under `tech/`, tick boxes in skill READMEs and [growth/checklists.md](growth/checklists.md). Commit at least 4 days a week, even small commits.
- **Sunday:** review the week, fill in the log and commit.
- **First Sunday of the month:** monthly review from [logs/monthly/_template.md](logs/monthly/_template.md).
- **End of each quarter:** review with [growth/reviews/quarterly-review-template.md](growth/reviews/quarterly-review-template.md).
